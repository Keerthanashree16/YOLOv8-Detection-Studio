# YOLOv8 Detection Studio

## Overview

YOLOv8 Detection Studio is a modern Computer Vision application developed to demonstrate real-time object detection, object tracking, and visual analytics using state-of-the-art deep learning techniques.

The platform provides an intuitive interface for analyzing images, videos, and live camera streams while generating detailed detection insights and performance analytics. The project highlights practical applications of Computer Vision and AI in surveillance, traffic monitoring, retail intelligence, and smart automation systems.

## Key Features

### Object Detection
- Real-time object detection using YOLOv8

## Installation

### Clone Repository

```bash
git clone <repository-url>
cd YOLOv8-Detection-Studio
```

### Install Dependencies

```bash
npm install
```

### Configure Environment Variables

Create a `.env.local` file:

```env
GEMINI_API_KEY=YOUR_API_KEY
```

### Start Development Server

```bash
npm run dev
```

Application will be available at:

```text
http://localhost:3000
```
